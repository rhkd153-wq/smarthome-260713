## 1. 앱의 목적과 철학

- **누구나(평가자) 사용 가능한 스크리닝 도구**: 작업치료사가 아니어도 문답을 따라가면
  대상자에게 맞는 스마트 홈 환경수정 솔루션이 도출되도록 설계.
- 근거: 델파이 연구 기반 **스마트 홈 가정 환경 수정 프로그램**(양식지 1·2·3) +
  **OTPF-4**(AOTA, 2020) 수행기술(Table 7)·신체기능(Table 9) + 국내 현장 조사
  공간별 환경수정 체크리스트.
- 게임형 UX: NPC **문스(🤖)** 가 한 화면에 한 질문씩 안내하고 즉시 피드백.
  진행에 따라 집이 자라나는 진행 비주얼. 어린이·고령자도 부담 없이 진행.

## 2. 평가 흐름 (4단계)

1. **시작(인트로)** — 의뢰 기관·담당자 입력(선택), 저장된 평가 이어하기
2. **공간 평가** — 미니 평면도에서 공간 선택 → 공간마다:
   - ① **활동 수행도** (양식지 2): 미경험 / 못함·안함(1) / 도움받아 함(2) / 독립적(3)
     → 1·2 = 제한 활동 = 솔루션 대상
   - ② **환경 안전 점검** (국내 조사 기반): 문스가 예/아니요 질문
     → "예"면 추천 도구·적용법 즉시 안내 후 최종 솔루션에 수집
3. **개인 능력·환경** — 한 질문씩 위저드: 연령대·장애 유형/정도·실내 보행·
   손의 기능적 사용·대화 가능·생활불편 인식 / 스마트폰·OS·Wi-Fi·가구·주거 형태·
   통합 제어판·IoT 경험·보유 브랜드·기존 가전. 답할 때마다 문스가 임상 팁 제공.
4. **솔루션 제안서** — 하위 탭: 📋요약 / 🏠설계도 / 🛒기기·구매 / 📝계획·교육 / 📈추적

## 3. 평가 대상 공간·활동 (양식지 2·3)

| 공간 | 작업 | 대표 활동 |
|------|------|-----------|
| 현관 | 외출/귀가, 손님·택배 응대 | 잠금장치 해제, 현관문 여닫기, 보안 활성화, **신발 신기·벗기**, 초인종 |
| 침실 | 잠들기/깨기, 야간 이동, 시간 보내기 | 무드등, 조명 스위치, 커튼, 전원 제어, 습도, 난방, 전동침대, 공기질, 알림 |
| 거실/부엌 | 시간 보내기, 건강 관리, 반려동물 | TV/에어컨, 온습도, 커튼, 조명, 체중, 운동, 심박, 펫 모니터링·급식 |
| 화장실 | 개인위생, 화장실 관리 | 조명, 온습도 모니터링, 환풍기 |

## 4. 솔루션 도출 로직 (핵심)

### 4-1. 작업수행 분석 레이어 (OTPF-4 기반)
- 각 활동을 **정상 수행 단계**로 분해하고 단계마다 필요한 **수행기술**(한글 어휘 15종:
  뻗기·굽히기·쥐기집기·쥐고돌리기·조작하기·협응하기·밀기당기기·들어올리기·걷기·
  옮기기이동·힘조절·부드러운움직임·자세유지·지구력·말하기의사소통)을 태깅.
- 개인 능력(손 기능·실내 보행·의사소통) → **막힌 수행기술 자동 추론** → 단계별로
  빨간 하이라이트 + "막힌 수행기술 → 아래 솔루션이 이 동작을 제거·대체" 요약.
- 예: SCI·전동휠체어 사용자의 현관문 열기 = ①손잡이 쥐고 돌리기 ②밀기·당기기
  ③문턱 넘기 모두 막힘 → 스윙식 자동문(동작 제거) + 레버 손잡이·문턱 경사판(물리 수정).

### 4-2. 제어 인터페이스 결정 트리
- 손 조작 가능 → 리모컨/스마트폰 앱
- 고정 시 조작 가능 → 거치형 리모컨
- 손 불가 + 대화 가능 → 스마트 스피커(음성, Wi-Fi 필수)
- 손 불가 + 발음 부정확/발화 불가 → AAC 앱 · 센서 자동화
- Wi-Fi 없음 → BLE(스위치 로봇 등) 우선, Wi-Fi 기기는 "구축 필요" 표시

### 4-3. 스마트 홈 기기 추천
- 활동별 적정 기술 후보(Wi-Fi/BLE + 기기 목록, 양식지 3) 중 개인·환경 조건으로 필터.
- **푸쉬풀 도어락은 스마트홈 기기로 분류** (스마트폰·스마트홈 연동 버전 존재).
- 키트 2등급: 초보자(플러그앤플레이) / 숙련자(허브·센서·자동화) — IoT 경험으로 기본값.
- 연결 구조 안내: Wi-Fi 직결 / 스마트 허브(Zigbee·Thread·Matter) / IR 리모컨 허브 / BLE.
- 플랫폼 추천: 보유 브랜드·OS 기반 점수화 (SmartThings·LG ThinQ·Apple 홈·Google Home·
  헤이홈·기가지니).

### 4-4. 로우테크 환경수정 (활동별 임상 큐레이션)
- 카탈로그 13종: 접이식 의자, 긴 구둣주걱, 문턱 경사판, 레버형 손잡이, 리처,
  그랩바, 미끄럼방지 매트, 목욕의자, 대형버튼 리모컨, 스위치 하향 이설, 야간등,
  침대 난간, 커튼 조작봉. (로커형 스위치판은 배선 교체 부담으로 제외)
- **활동별로 임상적으로 맞는 항목만 지정** (태그 교집합 오매칭 방지):
  신발 신기 → 접이식 의자·구둣주걱 / 문 열기 → 레버 손잡이·경사판 / TV → 대형 리모컨 등.

### 4-5. 환경 안전 점검 (국내 현장 조사, 34항목)
- 현관(6): 문턱→발판·손잡이, 문고리→레버형, 어두움→센서등, 미끄럼→방지,
  신발→벽걸이 접이식 의자, 휠체어→경사로(1:12)
- 화장실(9): 이동식 변기, 미끄럼 스프레이, LED, 수납장, 안전바, 샤워기,
  안전손잡이, 목욕의자, 라이프스타일 수정(18시까지 2L)
- 침실(7): 세로/가로 안전손잡이, 스탠드, 언어피드백 스피커, 서랍장, 비상 도구상자, 간이 의자
- 거실/부엌(12): AFO·4발지팡이, 안전손잡이, 발바닥 스티커, 리모컨 LED, 레버 문고리,
  전선정리, 실내 지팡이, 창문 손잡이, 보조발판, 가스차단기, 가구 재배치
- 문스가 예/아니요로 묻고 "예"만 최종 제안서 [환경 안전·수정] 카드에 수집
  → **임상적 의사결정 지원**.

## 5. 제안서(결과) 구성

- **요약**: 완료 배너, 대상자 주요구, 대상자 정보, 권장 제어 인터페이스, 통계
- **설계도**: 2D 평면 설계도(공간별 기기 배치·범례), 공간별 스마트홈 기술(+작업수행
  분석 블록), 공간별 로우테크, 환경 안전·수정(점검 결과)
- **기기·구매**: 키트 구성(초보/숙련 전환 가능), 권장 플랫폼·기존 가전 활용, 연결 구조·구매 안내
- **계획·교육**: 사용자 교육 체크리스트, OTPF-4 수행기술 근거표(효과적/비효과적), 중재 계획
- **추적**: 1~4주차 재평가 (도움받아 함 → 스스로 함), 활동별 전후 비교 카드
- 인쇄/PDF, JSON 내보내기/불러오기, 기록(지난 평가) 관리

## 6. 그동안의 주요 의사결정

1. 숫자 척도 대신 **말로 된 수행도 선택지** (미경험/못함/도움받아/독립적)
2. **공간 중심 흐름**: 공간 선택 → 그 공간의 활동만 평가 (중복 활동은 1회만)
3. 스마트폰 없으면 OS 질문 생략 등 **조건부 질문**
4. 주요구(현재 활동 수준에서 확인) 중심 필터링 — 옵션 B
5. 게임화: A(자라는 집) + C(문스 즉시 피드백) + D(화면 전환 애니메이션)
6. **로봇은 보류**, 로우테크는 함께 검증하며 추가
7. 핵심 활동부터 작업수행 분석을 붙이고 반응 보고 확장
8. 문턱 경사판·구둣주걱·리처 = 현장에서 실제 추천하는 항목 (검증됨)
9. 활동별 로우테크는 **큐레이션 방식** (자동 태그 매칭의 오추천 방지)
